About

Every disc's flight numbers, description and specs come from Marshall Street Disc Golf's Interactive Flight Guide, and each disc links back to its page there.

The estimated flight paths are drawn from those numbers, by a model fitted to the flight curves Marshall Street publish for each disc.

The popular molds shown by default were picked from OTB Discs' best sellers.

The code is on GitHub.
